# powerset

指定した要素数の集合 `{0, 1, ..., n-1}` の冪集合を列挙し、各部分集合を 1 行ずつ標準出力に表示する Rust プログラムです。`n` が `0` の場合は空集合だけを出力します。

## Podman で実行

```sh
podman build -t powerset .
podman run --rm powerset 3
```

出力例:

```text
[]
[0]
[1]
[0, 1]
[2]
[0, 2]
[1, 2]
[0, 1, 2]
```

出力件数は `2^n` です。部分集合を 1 件ずつ出力するため、全件を一度にメモリへ保持しません。

## テスト

テストもコンテナ内で実行します。

```sh
podman run --rm -v "$PWD:/app" -w /app rust:1.85-alpine cargo test
```

このテストは、要素数 0・1 の結果と、要素数 3 で 8 個の異なる部分集合が得られることを確認します。
